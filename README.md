

# 🏠 BoardingHub

BoardingHub is a full-stack boarding place management and booking platform designed to help people easily find suitable boarding places while enabling boarding owners to manage their properties efficiently.

The platform consists of:

- 📱 Mobile Application (React Native)
- 🌐 Web Application (Next.js)
- 🗄️ PostgreSQL Database
- ⚡ REST API
- 🔐 Secure Authentication
- 📍 Location-based Search

---

## 🚀 Project Vision

Finding a suitable boarding place is often difficult due to scattered information, outdated listings, and lack of reliable booking systems.

BoardingHub aims to provide a modern digital solution where:

- Boarding owners can register and manage their properties.
- Users can search, compare, and book boarding places based on their preferences.
- Both parties can communicate through a secure and user-friendly platform.

# ✨ Features

## 👤 Boarding Seeker

- User Registration & Login
- Search boarding places
- Filter by location, price, gender, and amenities
- View boarding details
- Save favourite boarding places
- Book boarding places
- View booking history
- Leave ratings and reviews

## 🏠 Boarding Owner

- Owner Registration & Login
- Add new boarding places
- Upload boarding images
- Edit boarding details
- Manage room availability
- Accept or reject booking requests
- View booking history
- Manage profile
